# ChatGPT Quick Delete / Archive / Bulk Delete

Delete or archive the current ChatGPT chat with a keyboard shortcut, or multi-select chats in the sidebar and delete / archive them in bulk. Matches the native ChatGPT web interface style.

快捷键删除或归档当前 ChatGPT 对话；在侧边栏多选对话，批量删除或归档。界面复用 ChatGPT 网页版原生样式。

## Features / 功能

| Action / 操作 | macOS | Windows |
| --- | --- | --- |
| Delete current chat / 删除当前对话 | ⌥⇧D | Alt+Shift+D |
| Archive current chat / 归档当前对话 | ⌥⇧A | Alt+Shift+A |
| Toggle multi-select / 开启或退出多选 | ⌥⇧M | Alt+Shift+M |
| Select current chat / 选中当前对话 | ⌥⇧S | Alt+Shift+S |
| Open settings / 打开设置 | ⌥⇧, | Alt+Shift+, |

- Shortcuts can be changed or turned off in settings. / 快捷键可在设置中修改或关闭。
- Choose what opens after deleting or archiving: a new chat, the previous chat or the next chat. / 可选择删除或归档后打开新对话、上一个对话或下一个对话。
- Deleting asks for confirmation with ChatGPT's own dialog by default. / 删除前默认使用 ChatGPT 原生确认框。

## Install / 安装

1. Install userscript manager [Tampermonkey](https://www.tampermonkey.net/)

   安装 [Tampermonkey](https://www.tampermonkey.net/) 用户脚本管理器。

2. Install the script from Greasy Fork: [ChatGPT Quick Delete / Archive / Bulk Delete](https://greasyfork.org/scripts/599856)

   在 Greasy Fork 安装脚本：[ChatGPT 快捷删除 / 归档 / 多选批量删除](https://greasyfork.org/scripts/599856)。

3. Refresh [ChatGPT](https://chatgpt.com/).

   刷新 [ChatGPT](https://chatgpt.com/)。
